KuCoin Radar v2.1 — Pembetulan Horizontal Line Drag
====================================================

Fokus: membolehkan horizontal line sedia ada digerakkan atas/bawah tanpa dipadam.

CARA GUNA
1. Buka /chart/, pilih coin dan timeframe seperti biasa.
2. Tekan "━ Horizontal" lalu klik chart untuk hasilkan satu garis.
3. Masih dalam mod Horizontal, klik/touch tepat pada garis kuning dan SERET naik/turun.
   Garis sedia ada akan bergerak, tiada garis kedua dicipta.
4. Sebagai alternatif, tekan "⌖ Pilih/Edit", kemudian seret garis.
5. Untuk harga tepat, double-click pada garis (desktop) dan masukkan harga USDT.
6. Harga baharu disimpan automatik selepas drag dilepaskan. Refresh untuk semak.

LANGKAH UPDATE
1. Sekiranya ada lukisan penting, buka Full Chart lalu klik "Backup JSON" dahulu.
2. Extract ZIP "GitHub_Update" dan upload isinya ke root repository GitHub signals.
3. Commit changes, kemudian semak Render Auto-Deploy = Live.
4. Buka /chart/ melalui Chrome dan refresh (Cmd+Shift+R di Mac).
5. Uji seret horizontal line, kemudian reload: harga dan lukisan harus kekal.

Ujian kod automatik lulus. Belum diuji pada deployment Render sebenar.
